# LuLu & FuSE

LuLu & FuSE is a production-oriented dating platform scaffold for consenting adults aged 18+.

## Included

- NestJS API with auth, profile, consent, and report modules
- Next.js web app with onboarding and dashboard screens
- Prisma schema covering users, profiles, consent, verification, and reports
- Docker Compose for local Postgres and Redis
- Kubernetes, Terraform, CI/CD, and monitoring placeholders

## Quick start

1. Install dependencies: npm install
2. Start infrastructure: docker compose up -d
3. Start the app: npm run dev

## Notes

The repository is intentionally structured as a strong foundation for V1.0 with production-grade architecture patterns, security hooks, and test coverage.
