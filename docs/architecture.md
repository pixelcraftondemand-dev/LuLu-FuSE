# LuLu & FuSE Architecture

## Overview

LuLu & FuSE uses a modular monorepo with a NestJS API, a Next.js web application, PostgreSQL, Redis, and cloud-native deployment assets.

## Core principles

- Safety-first onboarding and age verification
- Privacy-preserving consent flows
- Scalable event-driven services
- Observability and security by default

## Runtime components

- API: NestJS + TypeScript
- Web: Next.js + React
- Database: PostgreSQL + Prisma
- Cache: Redis
- Storage: AWS S3 + CloudFront
- Deployments: Kubernetes + Terraform + GitHub Actions
